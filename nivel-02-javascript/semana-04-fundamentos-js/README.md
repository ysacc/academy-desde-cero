# Semana 4 — JavaScript: fundamentos y lógica

## Contexto

Ya puedes construir y estilizar una interfaz. Esta semana empiezas a programar comportamiento con variables, operadores, condicionales, ciclos y funciones.

## Objetivos

Al finalizar la semana deberías poder:

- Crear variables con `let` y `const`.
- Reconocer tipos primitivos.
- Utilizar operadores aritméticos, lógicos y de comparación.
- Resolver decisiones con condicionales.
- Crear funciones con parámetros y retorno.
- Dividir un problema en pasos pequeños.
- Ejecutar tests locales y corregir errores de lógica.

## Starter

Usa el starter de la semana. Las funciones están preparadas para que completes su lógica sin modificar su contrato.

## Homework

Completa:

```text
nivel-02-javascript/semana-04-fundamentos-js/solution/index.js
```

Debes implementar y exportar:

```js
sumar(a, b)
esPar(numero)
calcularDescuento(precio, porcentaje)
calcularPromedio(numeros)
clasificarEdad(edad)
```

### Requisitos obligatorios

- No devolver valores hardcodeados.
- Validar casos básicos cuando corresponda.
- Usar funciones con `return`.
- Mantener nombres claros.
- No modificar los tests.
