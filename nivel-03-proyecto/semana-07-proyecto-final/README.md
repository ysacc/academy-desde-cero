# Semana 7 — Proyecto final guiado + Git/GitHub

## Contexto

Ya trabajaste HTML, CSS, responsive, JavaScript, DOM y APIs. Esta semana vas a integrar todo en un proyecto final pequeño pero completo.

## Objetivos

Al finalizar la semana deberías poder:

- Definir alcance y requisitos de un proyecto pequeño.
- Dividir el trabajo en tareas.
- Organizar archivos y responsabilidades.
- Trabajar con commits descriptivos.
- Integrar HTML, CSS, JavaScript y una API.
- Explicar decisiones técnicas.
- Preparar el proyecto para Code Review.

## Starter

Utiliza la plantilla de planificación de esta semana para definir problema, usuario, MVP, API y tareas antes de programar.

## Homework

Completa un MVP funcional que incluya:

- HTML semántico.
- CSS organizado.
- Responsive design.
- JavaScript modularizado de forma razonable.
- Consumo de una API pública.
- Estado de carga.
- Estado de error.
- Al menos una interacción del usuario.
- Repositorio Git con historial de commits entendible.

### Requisitos del repositorio

- README inicial.
- Código organizado.
- Sin errores visibles en consola durante el flujo principal.
- Commits descriptivos.

## ⭐ Challenge

Agrega una segunda interacción útil, como filtros, ordenamiento, favoritos o paginación simple.

## Tests locales

```bash
npm run test:week07
```

Además prueba manualmente:

- flujo principal;
- responsive;
- error de API;
- consola del navegador.

## Entrega

1. Sube el proyecto a tu propio repositorio de GitHub.
2. Revisa que el README permita entender qué hace el proyecto.
3. Envía el enlace al instructor.

## Criterios de evaluación

Se evaluará alcance, funcionamiento, organización, razonamiento técnico, uso de Git y capacidad de explicar decisiones.
