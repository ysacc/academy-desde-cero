# Semana 8 — Code Review, README, Deploy y presentación

## Contexto

La última semana cierra el ciclo profesional: revisar, corregir, documentar, publicar y explicar el proyecto.

## Objetivos

Al finalizar la semana deberías poder:

- Recibir y aplicar observaciones de Code Review.
- Mejorar legibilidad y organización sin romper funcionalidad.
- Escribir un README útil.
- Publicar una aplicación web.
- Explicar arquitectura, decisiones y dificultades.
- Presentar tu proyecto de forma breve y técnica.
- Identificar próximos pasos de mejora.

## Entrega final

Tu repositorio debe incluir:

- aplicación funcional;
- README completo;
- enlace público al deploy;
- historial de commits razonable;
- sin errores críticos visibles en consola;
- código que puedas explicar y modificar.

## README esperado

Debe incluir como mínimo:

- nombre del proyecto;
- descripción;
- funcionalidades;
- tecnologías utilizadas;
- instrucciones para ejecutarlo;
- API utilizada;
- enlace al deploy;
- aprendizajes o decisiones relevantes.

## Presentación final

Prepara una presentación de 3–5 minutos con:

1. problema o idea;
2. solución;
3. demo del flujo principal;
4. una decisión técnica relevante;
5. una dificultad y qué aprendiste al resolverla.

## Tests locales

```bash
npm run test:week08
```

Después realiza una revisión manual completa del sitio publicado.

## Entrega

Envía al instructor:

1. enlace del repositorio de GitHub;
2. enlace del deploy.

## Criterios de evaluación

Se evaluará funcionamiento, responsive, integración de API, calidad del código, README, uso de Git, aplicación de feedback, presentación y capacidad de explicar decisiones.

> La IA puede utilizarse como apoyo, pero debes poder explicar y modificar todo el código presentado.
