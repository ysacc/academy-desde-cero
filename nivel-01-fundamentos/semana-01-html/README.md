# Semana 1 — Web, HTML semántico y Git

## Contexto

Esta semana vas a construir tu primera página web y empezarás a utilizar Git desde el inicio. El objetivo no es memorizar etiquetas, sino comprender cómo se estructura una página y aprender a trabajar de forma ordenada.

## Objetivos

Al finalizar la semana deberías poder:

- Explicar la función de `html`, `head` y `body`.
- Utilizar etiquetas HTML básicas y semánticas.
- Crear enlaces, imágenes, listas y formularios simples.
- Comprender repositorio, commit y branch.
- Ejecutar tests locales y corregir requisitos faltantes.

## Starter

Puedes utilizar el material inicial de esta semana como punto de partida. Los comentarios `TODO` indican partes que debes completar.

## Homework

Completa:

```text
nivel-01-fundamentos/semana-01-html/solution/index.html
```

### Requisitos obligatorios

- `<!doctype html>`.
- `<html lang="...">`.
- `<meta charset>`.
- `<meta name="viewport">`.
- Un `<h1>` con tu nombre.
- Descripción personal.
- Imagen con `alt`.
- Lista de al menos 3 intereses.
- Al menos 2 enlaces.
- Formulario con nombre, correo, mensaje y botón de envío.

## ⭐ Challenge

- Agregar favicon.
- Agregar meta description.
- Usar coherentemente `header`, `main`, `section` y `footer`.

## Tests locales

Ejecuta:

```bash
npm run test:week01
```

No modifiques los tests. Corrige tu solución hasta que todos los requisitos obligatorios pasen.

## Entrega

1. Sube tu solución a tu propio repositorio de GitHub.
2. Mantén un historial de commits entendible.
3. Envía al instructor el enlace de tu repositorio.

## Criterios de evaluación

- Tests obligatorios en verde.
- HTML legible y ordenado.
- Uso razonable de semántica.
- Puedes explicar lo realizado y modificarlo si se te solicita.
