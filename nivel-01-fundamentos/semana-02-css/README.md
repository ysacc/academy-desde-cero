# Semana 2 — CSS y maquetación

## Contexto

La página ya tiene estructura. Ahora vas a separar contenido y presentación, entender el box model y construir una interfaz más organizada con estilos reutilizables.

## Objetivos

Al finalizar la semana deberías poder:

- Enlazar una hoja de estilos externa.
- Usar selectores por etiqueta y clase.
- Comprender cascada básica y reutilización.
- Aplicar tipografía, color, espaciado y box model.
- Inspeccionar estilos con DevTools.
- Construir una primera maquetación visual coherente.

## Starter

Utiliza el starter de la semana como punto de partida. Completa los `TODO` sin convertir los estilos en una copia exacta de un ejemplo.

## Homework

Crea:

```text
nivel-01-fundamentos/semana-02-css/solution/index.html
nivel-01-fundamentos/semana-02-css/solution/styles.css
```

### Requisitos obligatorios

- Enlazar `styles.css` con `<link rel="stylesheet">`.
- Aplicar estilos al `body`.
- Definir una familia tipográfica.
- Utilizar al menos 3 clases diferentes.
- Aplicar `margin` o `padding`.
- Usar al menos un `border`, `border-radius` o `box-shadow`.
- Estilizar enlaces.
- Estilizar el botón.
- Evitar estilos inline como solución principal.

## ⭐ Challenge

Crear una tarjeta de perfil claramente diferenciada y reutilizable.

## 🔥 Challenge avanzado

Definir variables CSS en `:root` y reutilizarlas.
