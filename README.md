# Academy Desde Cero

Ruta práctica para aprender desarrollo web desde cero mediante retos semanales, proyectos y validación local.

## Modalidad

- 8 semanas.
- 32 horas en vivo.
- 2 clases por semana.
- 2 horas por sesión.
- 4 horas en vivo por semana.

## Cómo funciona

Cada semana contiene:

- Contexto y objetivos de aprendizaje.
- Homework.
- Challenges opcionales.
- Tests locales para validar requisitos mínimos.
- Entrega mediante repositorio propio del alumno.

La dinámica detallada de las clases se mantiene en los archivos `INSTRUCTOR.md` y no forma parte del material del alumno.

## Regla de avance

Una semana se considera lista para revisión cuando:

1. El alumno completa la tarea en local.
2. Ejecuta los tests de la semana.
3. Corrige hasta que todos los tests obligatorios pasen.
4. Sube su solución a su propio repositorio de GitHub.
5. Envía el enlace del repositorio al instructor.
6. El instructor realiza Code Review y valida comprensión, calidad y decisiones técnicas.

> Los tests no se ejecutan automáticamente en GitHub y no reemplazan el Code Review.

## Ruta inicial

| Semana | Tema | Resultado principal |
| --- | --- | --- |
| 1 | Web + HTML + Git | Página personal semántica |
| 2 | CSS | Página personal estilizada |
| 3 | Responsive + Flexbox + Grid | Portfolio responsive |
| 4 | JavaScript fundamentos | Lógica y funciones |
| 5 | Arrays + objetos + DOM + eventos | Aplicación interactiva |
| 6 | Asincronía + fetch + JSON + APIs | App con API pública |
| 7 | Git/GitHub + proyecto final | Proyecto guiado |
| 8 | Code Review + README + Deploy | Proyecto publicado y presentado |

## Tests locales

Ejemplo:

```bash
npm run test:week01
```

Cada semana documenta su comando correspondiente.

Consulta [docs/metodologia.md](docs/metodologia.md) para conocer la dinámica de trabajo y [docs/evaluacion.md](docs/evaluacion.md) para el sistema de evaluación.
